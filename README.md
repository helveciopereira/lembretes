# Lembretes

Widget de lembretes e tarefas para a Área de Trabalho do Windows 10/11.

## Instalar

1. Baixe o instalador:
   **[Lembretes-win-Setup.exe](https://github.com/helveciopereira/lembretes/releases/latest/download/Lembretes-win-Setup.exe)**
2. Abra o arquivo baixado. Não precisa ser administrador nem instalar mais nada.
3. Se o Windows mostrar **"O Windows protegeu o computador"**, clique em **Mais informações** →
   **Executar assim mesmo** (o programa não tem assinatura digital paga).
4. Pronto: o atalho **Lembretes** aparece na Área de Trabalho e no Menu Iniciar.

## Auto update

O Lembretes se atualiza sozinho: quando sai uma versão nova, ele a baixa em segundo plano e
reinicia num momento em que você não está usando. Suas tarefas ficam só no seu computador.

As versões publicadas estão em [Releases](https://github.com/helveciopereira/lembretes/releases).
